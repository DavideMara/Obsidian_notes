### HTTP
HyperTextTransferProtocol
Scambio da client e Server per ogni richiesta, una serie di scambi in cui si dà la garanzia di chi chiede
// def TCP e def TLS // 
// image simil triple handshake //
Uno dei rischi pre https era il man in the middle (proprio per questo implementiamo ad es il TLS) 
Ogni tipo di implementazione porta un maggiore costo di sviluppo e manutenzione

#### Funzionalità
// velocemente e non nello specific// 
 - Cache
 - CORS: richiesta tra domini tipo
 - Autenticazione : attraverso i layer specifici
 - Proxy : es per intercettare richieste
 - Sessioni : instanze di comunicazione in cui lascio aperto un canale
 
ATTENZIONE : http è sateless, cioè non c'è collegamento tra due richieste consecutive. Per questo si usano i cookies
