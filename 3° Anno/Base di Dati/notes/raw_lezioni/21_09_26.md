# Lezione - Intro a DB
## Sistema di Base di Dati
Per basi di dati parliamo di una collezzione di dati che sono correlati tra loro. Questi dati si possono memorizzare. 
Proprietà implicite:
        - rappresenta un minimondo o universo del discorso (changes sul minimondo riflettono sulla base di dati)
        - è una collezione di dati logicamente coerenti con un signifato intrinseco
        - è ideata con dati per uno scopo specifico (quindi determinato gruppo user, app for user ecc)
        
Un isstema di gesitone DB (Databases Managment Sys) -> software per la definizione, costruzione, manipolazione e condivisione DB per varie app

** Sistema di Base di dati = Base di Dati + software DBSM **

### Caratteristiche dell'approccio con BD
Caratteristiche di un approccio based su un gestione di files: 
- Natura Autodescrittiva di un sistema di BD;
- Separazione tra programs e data, ed astrazione data;
- Suppoerto di multiple views on the data
- Sharing of the data e gestione delle transaction in un ambiente multiuser

#### Natura
Un sys BD contiene anche una descrizione completa della sua struct e dei suoi vincoli chiamata catalogo di sistema:
    - la struttura di ogni file
    - tipo e format di mem di ogni dato
    - vincoli sui dati
