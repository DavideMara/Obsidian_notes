Installazione

snip si installa come un qualsiasi pacchetto npm: e sufficiente avere Node.js e git gia disponibili nel PATH. L'installazione globale rende l'eseguibile utilizzabile da qualunque cartella.

  1. Requisiti: Node.js 18 o superiore, git
  2. Installazione globale: npm install -g snip
  3. Primo avvio: snip init crea ~/.snip/config.json e la cartella snips/
$ snip init
Creato      ~/.snip/config.json
Creatata    ~/snips/
Pronto. Digita 'snip list' per vedere gli snippet.

Comandi

I comandi operano sulla cartella snips/ e si comportano come una normale CLI: ogni flag accetta una forma breve e una lunga, e le forme brevi si possono combinare fra loro.

  • snip new crea uno snippet e lo apre nell'editor configurato
    • --lang: forza il linguaggio dello snippet
    • --tag: assegna uno o piu tag, separati da virgola
  • snip list elenca gli snippet, raggruppati per linguaggio
    • --tag: mostra solo gli snippet con quel tag
    • --sort: ordina per name o per date
    • --json: emette un array JSON, utile per lo scripting
  • snip search ricerca full-text nel contenuto degli snippet
    • --regex: interpreta il termine come espressione regolare
    • --limit: limita il numero di risultati mostrati
$ snip list --tag bash --sort name
bash  backup disco        2026-09-24
bash  restart nginx       2026-09-25
js    parse json date     2026-09-26

Configurazione

Il comportamento di snip si personalizza tramite il file ~/.snip/config.json, creato automaticamente dal comando snip init. Ogni chiave è opzionale: quelle omesse vengono risolte con il valore predefinito indicato in tabella.

Chiavi riconosciute in config.json
Chiave Tipo Predefinito Descrizione
editor stringa vim Editor aperto dal comando snip new
defaultLang stringa javascript Linguaggio assegnato allo snippet quando manca il flag --lang
sync.remote stringa nessuno URL del repository git che ospita gli snippet
sync.auto booleano false Se true, esegue il push del repository a ogni salvataggio 
{
  "editor": "vim",
  "defaultLang": "javascript",
  "sync": {
    "remote": "git@github.com:matteo/snip-notes.git",
    "auto": true
  }
}

Il file config.json contiene l'URL del repository privato: aggungilo al .gitignore prima del primo commit, altrimenti le credenziali di accesso finiscono nella cronologia del repository.

  • Usa snip config --edit per modificare il file, invece di aprirlo a mano: il comando valida la sintassi JSON prima di salvare.
  • Le chiavi annidate si indicano con il punto: sync.auto equivale a scrivere l'oggetto sync con la chiave auto al suo interno.
